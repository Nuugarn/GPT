# 9garn

ระบบรายรับ-รายจ่ายแบบหลายบ้าน — v2

## ผลลัพธ์ของ v2
- รองรับ `บ้าน 1` และ `บ้าน 2` เป็นบ้านเริ่มต้น และรองรับการเพิ่มบ้านผ่าน `Locations`
- ตารางและสรุปของแต่ละบ้านแยกกันจริง
- รายรับ/รายจ่าย/เงินคงเหลือไม่ปะปนข้ามบ้าน
- ข้อมูลเก่าที่ไม่มี `location` ถูกเก็บไว้ ไม่ถูกเดาสุ่มว่าเป็นบ้านใด และแสดงเป็น `ยังไม่ระบุบ้าน`
- มี `Locations` sheet ในฐานข้อมูลพร้อมแล้ว
- เวลาใช้รูปแบบ `YYYY-MM-DDTHH:mm:ss` และ Apps Script ตั้ง timezone เป็น `Asia/Bangkok`
- การเลือกวันคำนวณ Balance สะสมตั้งแต่ต้นเดือนถึงวันที่เลือกภายในบ้านนั้น
- การเลือกหมวดหมู่ไม่กระทบ Balance
- ไม่มี Secret Token ที่ฝังอยู่ใน Frontend
- Backend ตรวจสอบชนิดรายการ จำนวนเงิน วันเวลา บ้าน และขนาดรูปภาพ

## โครงสร้าง Transactions
`id | datetime | location | type | category | title | detail | amount | imageUrl`

## โครงสร้าง Locations
`name | active`

หมายเหตุ: รายการเก่าที่ไม่มีบ้านไม่สามารถระบุบ้านอย่างถูกต้องได้จากข้อมูลเดิมเพียงอย่างเดียว จึงไม่ถูกกำหนดบ้านโดยอัตโนมัติ
